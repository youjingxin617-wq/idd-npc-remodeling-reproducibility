# Submission Upload Map

Date prepared: 2026-05-23

This document separates materials that should be submitted with the manuscript from materials that should be deposited in a public repository.

## Short Answer

Yes. Reproducibility materials should be prepared together with the manuscript, but they do not all need to be uploaded as supplementary files.

For this public-data transcriptomic study, the safest submission strategy is:

1. Upload the manuscript, main figures, and supplementary tables through the journal submission system.
2. Include a clear "Availability of data and materials" statement in the manuscript.
3. Deposit scripts, processed result tables, figure-generation code, and session information in a public GitHub or Zenodo-linked repository.
4. Do not upload raw GEO archives or large RDS intermediate objects unless the journal specifically asks for them.

## Submit With Manuscript

| Material | Submission route | Status |
|---|---|---|
| Manuscript DOCX | Main manuscript file | Ready locally |
| Main figures | Separate figure files if requested by journal | Ready locally |
| Supplementary Figure S1 | Supplementary figure file | Ready locally |
| Supplementary Tables S1-S16 | Supplementary files, preferably CSV or one XLSX workbook | Ready locally as CSV |
| Supplementary table index | Supplementary file or first sheet of XLSX workbook | Ready locally |
| Data availability statement | Manuscript Declarations section | Ready with GitHub repository URL |
| Author contributions, funding, competing interests | Manuscript Declarations section | Still needs author input |

## Deposit In Repository

| Material | Repository route | Reason |
|---|---|---|
| `scripts/` | GitHub or Zenodo-linked GitHub release | Allows reproduction of analysis and figures |
| Curated result tables | GitHub repository | Supports figure and table traceability |
| Supplementary tables | GitHub repository and journal upload | Useful for both readers and reviewers |
| Reproducibility README | GitHub repository | Explains how to rerun the workflow |
| Software/session information | GitHub repository; optionally supplementary file | Documents computational environment |
| File manifest | GitHub repository | Maps figures/tables to scripts |

## Exclude From Repository And Journal Upload

| Material | Reason |
|---|---|
| Raw GEO archives | Publicly available from GEO; large and redundant |
| Extracted raw GEO folders | Regenerated by download script |
| Seurat RDS objects | Large intermediate objects; can be regenerated |
| CellChat RDS objects | Large intermediate objects; can be regenerated |
| Slingshot/SCE RDS objects | Large intermediate objects; can be regenerated |
| Local IDE/cache files | Not reproducibility materials |
